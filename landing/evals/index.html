Which models work best with Oga

We give each model the same small jobs through Oga and check how it works. Does it follow the brief, stay inside its files, ask when it is stuck, and report honestly? As a lead, does it hand work to other models and check what comes back?

This is not a ranking of the smartest model. A strong model can still score low here if it ignores the brief.

What we test

On every job we also check the house rules: commit message format, only the files it was given, no stray files, and a report in the shape we asked for.
