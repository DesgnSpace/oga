Docs / Install

Get Oga onto your Mac

Oga needs macOS 14 or later. Windows and Linux aren't ready yet.

Install in one command

Downloads Oga and puts it in your Applications folder:

curl -fsSL https://downloads.desgn.space/oga/install.sh | sh

Install with Homebrew

If you already use Homebrew:

brew install --cask DesgnSpace/tap/oga

Build it yourself

For contributors, or to run something ahead of a release:

git clone https://github.com/yondifon/oga.git
cd oga
bun install
make install

A build of your own installs as Oga (local), alongside a released Oga rather than replacing it. Only one can run at a time — they share the same port and the same folder — so quit one before opening the other. make install quits whichever is open, starts the one it just built, and points the oga command at it.

Get new versions

Oga checks quietly when it opens. You can also choose Check for Updates from the Oga menu or the About section in Settings, then download and install a new version without leaving the app.

Check that it's running

Opening the app starts everything Oga needs. To confirm it answered:

curl http://127.0.0.1:7331/health

Use Oga from the terminal

Oga also gives you an oga command. It carries everything it needs, so it works without a checkout or any other tooling. Run oga on its own to see what it can do and how to start.
