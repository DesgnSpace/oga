Install Oga

Oga requires macOS 14 or later. Windows and Linux are coming soon.

Install with curl

Downloads and installs the app in one step:

curl -fsSL https://downloads.desgn.space/oga/install.sh | sh

Install with Homebrew

Oga ships its own cask through a tap:

brew install --cask DesgnSpace/tap/oga

Build from source

For contributors, or to run a build ahead of a release:

git clone https://github.com/yondifon/oga.git
cd oga
bun install
make install

A source build installs as Oga (local), next to a released Oga without replacing it. Only one can run at a time - they share port 7331 and ~/.oga - so quit one before opening the other. make install quits whichever is open, launches the one it just built, and points oga in ~/.local/bin at it.

Confirm it's running

The broker answers on 127.0.0.1:7331 once it's up:

curl http://127.0.0.1:7331/health

The oga command

make install links the compiled binary onto your PATH as oga. It carries its own runtime, so every command works with no Bun and no checkout. Run oga with no arguments any time for a list of commands and a first-run walkthrough.
