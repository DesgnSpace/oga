Oga docs

Keep working while something else gets done

Oga is an orchestrator for coding agents — the layer above the AI coding tools you already use.

You describe a piece of work. Oga decides which tool and which of your accounts should run it, hands it the brief along with what your project has already taught Oga, runs it in the background on only the files you allow, and tells you the moment it finishes or needs an answer.

Oga writes no code itself. It decides who does, and carries the work there and back.

Why hand work off

  • Your accounts don't share a limit. Running into a cap on one doesn't stop the rest.
  • It doesn't crowd out your own conversation. The brief and the answer live on the other account, not in the chat you're having.
  • Cheap work can go to a cheap model. A mechanical rename and a hard rewrite don't need the same one. Pick per piece of work, or let Oga pick.

What happens after you hand something off

  1. You describe the work and the folder it happens in.
  2. Oga picks an account and a model, unless you name one.
  3. You get an ID back straight away, and the work starts.
  4. You carry on with your own work.
  5. When it finishes, asks a question, or fails, you hear about it.

Oga sits in your menu bar on macOS. The coding agent you already use — Claude Code, Codex, OpenCode, Antigravity, or Pi — can hand work to it once the two are connected.

Get your first piece of work running

  1. Install Oga and open it.
  2. Add the accounts you want to hand work to, and connect your coding agent.
  3. Ask for the work in plain language.
  4. Get told when it's done, instead of watching it.

New to the command line? Type oga on its own to see the available commands and first-run steps.
