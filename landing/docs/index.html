Oga docs

What Oga is

Oga hands a task to one of your other AI accounts, runs it in the background with only the files you allow, and tells you the moment it needs you or finishes.

What it does

You hand Oga a prompt and a working directory. It picks a model, spawns a sandboxed worker on a different account, and returns a task ID the moment dispatch succeeds. The worker runs independently while you keep working. When it needs input, hits a question, or finishes, Oga tells you.

Oga runs on macOS as a menu-bar app with a local broker on 127.0.0.1:7331. Every AI coding agent that speaks MCP - Claude Code, Codex, OpenCode, Antigravity - can connect to it and delegate work to your other accounts.

Why delegate

  • Separate accounts, separate limits. A rate limit on one account does not block the whole session.
  • No context tax. A delegated worker's prompt and output do not consume the caller's context window.
  • Provider choice per task. A mechanical rename goes to a cheap fast model; a hard problem goes to a frontier model.

Quick start

  1. Install the app and confirm the broker answers curl http://127.0.0.1:7331/health.
  2. Connect your coding agent to http://127.0.0.1:7331/mcp and add a profile for each account you want to delegate to.
  3. Delegate a task by asking your agent to send off a piece of work.
  4. Follow it with oga watch <task-id>, running in the background at no cost while it works.

First time on the command line? Run oga with no arguments - it prints this same walkthrough.
